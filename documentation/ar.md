# شدة التأق (Brown)

[الشروط والمصادر والأذونات](https://elucenia.org/ar/tools/gravidade-da-anafilaxia)

## كيفية الاستخدام

استخدم الأداة في البوابة أو افتح index.html عبر خادم HTTP محلي. اختر اللغة، وأكمل الحقول، ثم أجرِ الحساب.

## المدخلات والوحدات

### الجلد وتحت الجلد: حمامى عامة أو شرى أو وذمة حول العين أو وذمة وعائية

`pele`

### تنفسي: ضيق نفس أو صرير أو أزيز أو انقباض بالصدر أو الحلق

`resp`

### هضمي: غثيان أو قيء أو ألم بطني

`gi`

### قرب الإغماء (دوخة) أو تعرق

`cardio`

### نقص أكسجة الدم (SpO₂ ≤ ٩٢%) أو زرقة

`hipoxia`

### انخفاض الضغط (الضغط الانقباضي \< ٩٠ mmHg لدى البالغ)

`hipotensao`

### تأثر عصبي: تشوش أو انهيار أو فقدان الوعي أو سلس

`neuro`

## إصدار الطريقة

Brown 2004: 3 درجات، أشدّ علامة؛ SpO₂≤92/ضغط انقباضي\<90/عصبي

## المعادلة الموثقة

تحدّد الدرجة بأشدّ علامة:

درجة 1 (خفيفة): الجلد وتحت الجلد فقط.

درجة 2 (متوسّطة): إصابة تنفّسية أو قلبية وعائية أو هضمية.

درجة 3 (شديدة): نقص أكسجة (SpO₂ ≤ 92% أو زرقة)، هبوط ضغط (الانقباضي \< 90 mmHg) أو تأثّر عصبي.

## الحدود والفئة السكانية

دُرس تصنيف Brown بأثر رجعي في تفاعلات فرط التحسس الجهازي في الطوارئ. ليست الشدة تعريفًا تشخيصيًا كاملًا ولا قاعدة علاجية مستقلة. يجب التحقق من العتبات العددية وتعريفات النسخة في المنهج الكامل؛ ولا يمكن استبدال العلامات وشروط التطبيق بالمجموع وحده.
